IT Infrastructure Health Monitoring System

Project Overview
The IT Infrastructure Health Monitoring System is a Python-based application developed using Streamlit and Psutil. It monitors system performance by displaying CPU, memory, and disk utilization with threshold-based alerts.

Features

 Real-time CPU utilization monitoring
 Memory utilization monitoring
 Disk usage monitoring
 Threshold-based alerts
 System information display
 Interactive dashboard using Streamlit

Technologies Used

 Python
 Streamlit
 Psutil

Project Structure

IT-Infrastructure-Health-Monitor/
│
├── app.py
├── requirements.txt
└── README.md

Installation and Setup

1. Clone the repository
git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project folder
cd IT-Infrastructure-Health-Monitor

3. Install dependencies
pip install -r requirements.txt

4. Run the application
streamlit run app.py

Monitoring Parameters
- CPU Usage
- Memory Usage
- Disk Usage

Purpose
This project demonstrates basic IT infrastructure monitoring, system performance analysis, Python programming, and dashboard development.
